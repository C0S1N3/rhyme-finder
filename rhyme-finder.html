押韵字数
单押匹配最后一个字音；双押 / 三押 / 多押匹配末尾 2 / 3 / 4 个字音；混押自动匹配尽可能多的字音并标注押数。
押韵方式
只押尾音：同十三辙韵部即可押（最宽松，如「天 tiān」押「年 nián」「远 yuǎn」）；精准韵母：韵母完全一致；全押：声母 + 韵母完全相同。
声调
说唱中一般声调不限；做「完全押韵」时可开启声调一致。

HOW TO功能说明

1什么是单押 / 双押 / 多押

指连续押韵的字音数量。单押只看最后一个字音，双押要求末尾两个字音都押（如「时间」↔「世间」），三押/多押依次类推。混押会自动匹配你能押上的最大长度，并在卡片右上角标注「2押」「3押」。

2只押尾音 vs 全押

只押尾音按十三辙韵部匹配，只要韵尾相近就算押（天 / 年 / 远 / 现），韵脚池最大；精准韵母要求韵母逐字相同；全押要求声母 + 韵母完全一致，最严格，适合「完全韵」。

3声调怎么选

中文说唱通常声调不限——靠节奏和韵尾就能成立；如果你写的是古风、旋律说唱或需要「同音韵」效果，可以开启声调一致让听感更整齐。

4小技巧

输入的词越长，能查到的双押 / 三押结果越准；点击任意韵脚卡片即可复制；「复制全部」一次带走整批词；英文单词按词尾发音匹配（如 night 押 light fight）。
