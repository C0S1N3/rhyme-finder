# 🎤 押韵词典 · RHYME DICTIONARY

> 🎧 找韵脚，写 punchline，先查词典。
> 为说唱创作者打造的中文押韵工具 —— 单押双押多押，尾音全押，一键切换。

🌐 在线体验：<https://rhyme-zone-f9d6h843g0z.qoder.zone>

---

## ✨ 功能亮点

- 📖 **12,000+ 离线词库** —— 常用词汇 + 说唱高频词，内置拼音标注，无需联网
- 🔢 **五种押韵字数** —— 单押 / 双押 / 三押 / 多押 / 混押，混押自动识别你能押上的最大长度
- 🎯 **三档押韵精度** —— 只押尾音（十三辙）/ 精准韵母 / 全押，从宽松到严格随心切
- 🎵 **声调控制** —— 声调不限（说唱惯例）/ 声调一致（旋律说唱、完全韵）
- 🌏 **中英双语** —— 中文按拼音韵部匹配，英文按词尾发音匹配（`night` → `light` / `fight`）
- 📋 **一键复制** —— 点卡片复制单个词，「复制全部」整批带走
- 📱 **全端响应式** —— 手机、平板、电脑都有舒适排版

## 🚀 快速开始

用浏览器直接打开 `rhyme-finder.html` 即可使用，无需安装任何依赖：

```
rhyme-finder.html      ← 双击打开这个
assets/app.js          ← 押韵匹配引擎
assets/data.js         ← 离线词库（12,000+ 词条）
_shared/fonts/         ← 字体
```

也可以起个本地服务部署到局域网：

```bash
python -m http.server 8123
# 打开 http://localhost:8123/rhyme-finder.html
```

## 🎛️ 使用指南

在搜索框输入词语（如 `天`、`时间`、`dream`），回车或点击 **SEARCH**，下方立刻铺开韵脚卡片。

| 选项 | 取值 | 什么时候用 |
| :--- | :--- | :--- |
| **押韵字数** | 单押 | 只押最后一个字音，韵脚池最大 |
| | 双押 / 三押 / 多押 | 末尾 2 / 3 / 4 个字音连续押，双押是 punchline 利器 |
| | 混押 | 自动匹配最大押数，卡片右上角标注「2押」「3押」 |
| **押韵方式** | 只押尾音 | 同十三辙韵部即可押（天 / 年 / 远 / 现），最宽松 |
| | 精准韵母 | 韵母完全一致，音色更统一 |
| | 全押 | 声母 + 韵母完全相同，写「完全韵」用这个 |
| **声调** | 声调不限 | 中文说唱默认选择 |
| | 声调一致 | 古风、旋律说唱、需要整齐听感时开启 |

## 💡 小技巧

- 📌 输入的词越长，双押 / 三押的结果越准 —— `时间` 比 `间` 能找到更准的双押
- 📌 搜完一次的词会进入「最近」，点一下就能重新查
- 📌 全押太严没结果？退回「只押尾音」，韵脚池立刻变大
- 📌 押韵词典只是弹药库 —— 节奏和语义，还得靠你 🔥
